# Hyper Elements Development Guidelines

Templates must use Hyper Elements (@hyper-elements/react). Before writing templates, read:
- `node_modules/@hyper-elements/react/GUIDE.md`
- `node_modules/@hyper-elements/react/REFERENCE.md`

Before finalizing:
- Run Hyper Elements validation.
- Fix errors and review warnings.
- Inspect outline().
- Render all four outputs.
- Preview email clients.
