Section 4

Breaking Changes & Step-by-Step Migration

Follow these upgrade steps carefully to ensure seamless migration to v2.0.

4.1. Consolidated Barrel Import Paths

ACTION REQUIRED

Sub-package deep imports like 'prism-ui/core' and 'prism-ui/components' have been unified into the top-level 'prism-ui' barrel export.

Deprecated Pattern (v1.x)Updated Standard (v2.0)
// v1.x (Deprecated) import { Button } from 'prism-ui/core'; import { Modal } from 'prism-ui/components/modal';// v2.x (Unified) import { Button, Modal } from 'prism-ui';

Automated Migration: Use `npx @prism-ui/codemod unify-imports` to automatically update all imports in your repository.

4.2. Modal & Dialog 'isOpen' Renamed to 'open'

ACTION REQUIRED

Standardized all boolean state props across primitives to align with native HTML5 dialog conventions.

Deprecated Pattern (v1.x)Updated Standard (v2.0)
// v1.x <Modal isOpen={isVisible} onRequestClose={handleClose} />// v2.x <Modal open={isVisible} onOpenChange={setIsVisible} />

Automated Migration: The codemod also renames `isOpen` to `open` and maps `onRequestClose` to `onOpenChange`.

Automated Codemod CLI

$ npx @prism-ui/codemod upgrade-v2 --write

Applies import consolidations and AST prop renames safely with dry-run support.
