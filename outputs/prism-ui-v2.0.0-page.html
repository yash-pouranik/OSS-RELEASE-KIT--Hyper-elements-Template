What's New in Version 2.0.0

All-New Accessible DatePicker

New Component

Fluid multi-view calendar engine with range selection, custom timezone localization, and seamless keyboard navigation (Arrow keys, Home/End, PageUp/Down).

Usage Example

import { DatePicker } from 'prism-ui'; <DatePicker mode="range" defaultValue={[new Date(), nextWeek]} onSelect={(range) => console.log(range)} />

Overhauled Headless Select

Overhauled

Re-engineered virtualized list engine with asynchronous search filtering, multi-selection chips, and portal-aware positioning.

Usage Example

Migration Guide

Upgrading from Prism UI v1.x to v2.0

Please review the breaking changes below before bumping versions in production.

Consolidated Barrel Import Paths

Sub-package deep imports like 'prism-ui/core' and 'prism-ui/components' have been unified into the top-level 'prism-ui' barrel export.

Before (v1.x)

// v1.x (Deprecated) import { Button } from 'prism-ui/core'; import { Modal } from 'prism-ui/components/modal';

After (v2.0)

// v2.x (Unified) import { Button, Modal } from 'prism-ui';

💡 Migration Tip: Use `npx @prism-ui/codemod unify-imports` to automatically update all imports in your repository.

Modal & Dialog 'isOpen' Renamed to 'open'

Standardized all boolean state props across primitives to align with native HTML5 dialog conventions.

Before (v1.x)

// v1.x <Modal isOpen={isVisible} onRequestClose={handleClose} />

After (v2.0)

// v2.x <Modal open={isVisible} onOpenChange={setIsVisible} />

💡 Migration Tip: The codemod also renames `isOpen` to `open` and maps `onRequestClose` to `onOpenChange`.
